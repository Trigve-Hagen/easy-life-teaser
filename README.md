# LifeModel — Preview Build

A read-only preview of the full LifeModel product. Every real page from the
product is here, described using its actual documentation and tutorial
content (sourced from the project's own `phase-docs.html`) — but with all
functional code stripped out: no API calls, no live data, nothing wired to
a backend. Each page carries a "$9.99/mo — unlock full functionality" call
to action.

This is a marketing/preview artifact, generated by a script
(`build_teaser.py`, in the main LifeModel repo) from the real product
source — never hand-maintained, regenerated any time the real product's
pages or tutorials change.

**Not the free download.** The genuinely working free tier (cleanup &
hardening, profile vault, form filler, email templating — no payment, no
account) is a separate product: https://github.com/Trigve-Hagen/lifemodel-cleanup-tools

Live at: https://trigve-hagen.github.io/lifemodel-teaser/
