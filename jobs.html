Phase 4: Job Application Automation (Indeed.com) Built

Documentation

Search Indeed, draft a resume from your actual vault data, and prepare a real Easy Apply submission for review — reusing Phase 2's AI field-mapping tool rather than a second matcher. Preparing an application logs in and fills the Easy Apply form but never clicks Submit; only the separate, explicit Submit application action does that, per the Security Checklist's "no silent auto-apply" rule. A prepared application's mapped fields are the same FormFillRun/FormFieldMapping rows Phase 2's Agent page already uses, so they can be reviewed/edited there too.

Once a job-search account (Email page) has the job-search categories seeded, real recruiter responses are linked back to the matching Application automatically (fuzzy-matched on company/job title): a rejection/offer/follow-up email just updates the application's status locally, while an interview request or recruiter screen drafts a calendar event proposal — reusing Phase 3's calendar integration — that only touches your real calendar once you explicitly confirm it, at which point the application flips to "interview scheduled."

Real-world caveats: Indeed's page structure and bot-detection can change or block automated login/search at any time — if search or prepare fails, that's Indeed's side, not a local bug. A resume PDF render requires Playwright's Chromium browser to be installed on this machine the same way Phase 2's form-filler does.

Tutorial

  1. Open the Jobs page and pick a profile.
  2. Under Job board accounts, add your Indeed login — the password is stored via your OS's secure credential store, never as plain text.
  3. Under Search criteria, add keywords/location/remote preference, then click Search Indeed on that row.
  4. Under Resume versions, click Draft new resume — it's built only from your actual Profile/CustomFields data, then review and Approve it (and optionally Render PDF to get a downloadable file).
  5. Back in the search results, pick your approved resume from the dropdown and click Create application on a posting.
  6. In Applications, click Prepare (fill Easy Apply) — this really logs in and fills the form, then stops. Review the result, then click Submit application to actually apply (you'll be asked to confirm).
  7. On the Email page, select the account you use for job hunting and click + Seed job-search categories in the Categories section so recruiter responses link back here automatically.
  8. Check Interview proposals on this page for any auto-drafted interview times — Confirm & push to add it to your real calendar and mark the application scheduled.
