Phase 9: Employer Info & Profit-Share Coalition Agent Built

Documentation

Models an employer and turns "10% of profit earned above last year's projected growth, split evenly across participating employees" into real, computable numbers instead of a verbal pitch. A proposal stores its baseline profit, projected growth rate, and requested pool percentage; the projected profit is computed from those the moment you save it, and the live projection — profit over projection, pool amount, per-employee share — recalculates on every page load from the current opted-in headcount and actual profit (once known), never a stale stored figure.

Consent is explicit, never assumed: a named colleague only counts toward the per-employee split once their status is set to opted_in — inviting someone or their silence never counts them in. Every consent-status change is logged with a timestamp for later reference.

Every number is a proposal, not an entitlement, until the employer has actually agreed in writing: moving a proposal's status to Active is blocked until you've attached a signed-agreement reference — a verbal "yes" is never treated as binding. Draft pitch renders the full proposal document (baseline, terms, opted-in participants, and current numbers) for you to review — it is never sent to your employer automatically.

Tutorial

  1. Open the Employer page and pick a profile.
  2. Click + Add employer and fill in the company/role basics.
  3. Select that employer, then click + Add proposal — enter the baseline profit, projected growth rate, and requested pool percentage for the year.
  4. Select the proposal. Add a few participants by name, then set each one's consent to opted_in as they actually agree — watch the per-employee share in the projection update as the opted-in count changes.
  5. Click Draft pitch to see the full proposal document rendered — copy it out and deliver it yourself; nothing here sends anything.
  6. Log each round of back-and-forth under Negotiation log as it happens.
  7. Once the employer has agreed in writing, enter a reference to that agreement and move the status to Active — notice it's rejected until the reference is filled in.
  8. Once year-end actual profit is known, set it on the proposal, then click Record payout from current numbers and mark it paid once distributed.

Work Assignments & Work Email Tracking (Steps 332–336) Built

A second, deliberately separate tracker on the same Employer page: real day-to-day work projects assigned to you by this employer — a title, real details, and an expected finish date you can revise as the deadline actually moves. This is not the same thing as Phase 11's "Work assignments" (Steps 32–35, described above): that feature is marketing-plan work an employer hands out to its own opted-in profit-share coalition participants, a B2B coalition-execution table. This one is personal — what the user themselves has been assigned — and lives in a completely separate database table under a different name (EmployerProjectAssignments, not WorkAssignments) precisely so the two are never confused in code or in the UI.

Once you link one of your already-connected email accounts to this employer, every real inbox sync automatically fuzzy-matches new messages against this employer's own open assignments (by title/details, entirely local — no remote model call, no new data-sharing permission needed) and links a confident match. An assignment with unread matched mail shows a real, live-computed "N new emails" badge — this is a live status shown when the page loads, never an OS-level push notification, a sound, or an email-of-its-own; this app has no push-delivery system anywhere. Opening the matched-email list doesn't clear the badge — only the explicit Mark seen action on each email does, so the count stays trustworthy.

Tutorial (work assignments)

  1. On the Employer page, select an employer and click + Add assignment — enter a real title, details, and an expected finish date.
  2. Under Work email account, pick one of your connected accounts from the dropdown and click Save — if you don't have one yet, add it on the Email page first.
  3. Sync that account's inbox (from the Email page, or via its own sync action) — any new message whose subject/body clearly matches an open assignment's title/details gets linked automatically.
  4. Back on the Employer page, look for the "N new emails" badge on the matching assignment; click Show matched emails to read them inline, then Mark seen on each — watch the badge count go to zero only once you've actually done that.
  5. Move an assignment's status to Completed once it's done — a completed/cancelled assignment stops absorbing new email matches, so old finished work doesn't keep collecting unrelated mail.
