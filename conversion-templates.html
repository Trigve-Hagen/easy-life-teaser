Phase 28: JSON Field Conversion Templates Built

Documentation

What this is: a reusable way to rename and move fields from one JSON shape into another — pure data movement, never arbitrary code. A template is a named list of mappings; each mapping takes a source dot-path and writes it to a target dot-path.

Templates: click + Add template to create a named, reusable set of mappings. Templates aren’t tied to any one file — build one for a shape you receive repeatedly and reuse it.

Field mappings: click Manage, then + Add mapping — a source field (dot-path into the input) and a target field (dot-path in the output). Order matters only where targets overlap.

Try it: paste or load sample JSON to see a live before/after preview as you add or remove mappings. Nothing is saved by the preview.

Apply to a file: upload a real JSON file and the converted result downloads immediately. Stateless by default — the input and output are not stored.

Keep a link to the result (Step 394): tick “Also keep a link to the result” before uploading and the same conversion is also written to a real URL you can open later, curl from a script, or hand to another tool in a pipeline. The inline download still happens exactly as before — the link is additive. Retention is deliberate: unlike the short-lived signed links the subscription service issues for installers, this is a single-user local vault, so a generated file stays available until you remove it.

Where else this engine lives: the same field-mapping idea is offered publicly on easylifeagents.com as a $1.99-per-conversion tool that runs entirely in the browser — nothing is uploaded, and that one requires no account. Subscribers additionally get a saved-conversions API (Step 399) that keeps a converted result server-side so it can be fetched again from another machine.

Access: this page is a paid-tier feature. The public front-page form on the product site is the free/one-off path and is unaffected by that gate.

Tutorial

  1. Open Conversion Templates and click + Add template. Name it after the shape you receive, e.g. “Orders v1”.
  2. Click Manage, then + Add mapping twice — try a plain rename (total → order.amount) and a nested one (cust.first → customer.firstName).
  3. Click Load sample data under Try it and watch the before/after preview update as you edit the mappings.
  4. Edit the sample JSON directly and confirm the preview updates as you type.
  5. Upload a real JSON file under Apply to a file and confirm the downloaded result matches what the preview showed.
  6. Now tick Also keep a link to the result and upload again. Open the link that appears — the file it serves should be byte-identical to the download, and named after your template.
