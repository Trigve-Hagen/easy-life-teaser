Phase 28: JSON Field Conversion Templates — Preview

Documentation

What this is: a reusable way to rename/move fields from one JSON shape into another — pure data movement, never arbitrary code. Three surfaces share the same engine: this page (free, saved templates, for you), the public gwm_site page (anonymous, $1.99/conversion, no account), and — once Step 230 lands — unlimited conversions bundled into the existing $9.99/mo LifeModel subscription. Only this page is built so far.

Templates: click + Add template to create a named, reusable list of field mappings. Templates aren't tied to a profile or company — the same engine that powers this page also powers the public, anonymous gwm_site tool.

Field mappings: click Manage on a template, then + Add mapping — a source field (dot-path into the input, e.g. address.city), a target field (dot-path in the output), and a transform: Rename/Copy both move the value as-is, Flatten spreads a nested object's own keys under the target path, and Stringify writes the value as a JSON string. A source field missing from a given input is skipped, never a crash; two mappings pointed at the same target field — last one wins, the real, documented behavior.

Try it: paste or load sample JSON under a template's Try it panel to see a live before/after preview as you add or remove mappings — computed by the same json_field_mapper.py engine the public $1.99 page's JavaScript port mirrors.

Apply to a file: upload a real JSON file under a template and it downloads the converted result immediately — stateless, nothing you upload is stored anywhere by this page.

Tutorial

  1. Open the Conversion Templates page and click + Add template.
  2. Click Manage on it, then + Add mapping a couple of times — try a plain rename and a flatten.
  3. Click Load sample data under Try it and watch the before/after preview update.
  4. Edit the sample JSON directly and confirm the preview updates as you type.
  5. Upload a real JSON file under Apply to a file and confirm the downloaded result matches what the preview showed.
